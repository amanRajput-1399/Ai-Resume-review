# 🚀 AI-Powered Mock Interview & Resume Review Platform

A full-stack web application designed to simulate real-world technical interviews, generate AI-driven dynamic questions, evaluate user responses, and streamline resume preparation workflows.

---

## 🛠️ Tech Stack

* **Frontend:** HTML, SCSS, JavaScript, Vite
* **Backend:** Node.js, Express.js
* **Database & Caching:** MongoDB, Redis
* **Security & Auth:** **JWT (JSON Web Token)** & Secure Middleware
* **AI Integration:** Google Gemini API
* **Other Tools:** Git, RESTful APIs

---

## ✨ Core Features

* **🔐 JWT Authentication:** Secure user registration, login, and protected route access using JSON Web Tokens.
* **🤖 AI-Driven Question Generation:** Dynamically creates customized technical and behavioral interview questions based on the selected tech stack and role.
* **💬 Interactive Mock Interviews:** Real-time interface allowing users to practice interview sessions and receive structural evaluations.
* **📄 Resume Parser & Generator:** Automated tools to parse user resumes and export clean performance reports/resumes in PDF format.
* **🔒 Secure Architecture:** Implements robust environment configurations and secure authentication middleware.
